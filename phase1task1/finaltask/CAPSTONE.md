Live Polyhouse Node Capstone

 Objective
Build a complete IoT monitoring system using ESP32 and DHT22.

 Components
- ESP32
- DHT22
- WiFi
- Zelbytes IoT Lab

 Data Flow
DHT22 → ESP32 → HTTPS + MQTT → Zelbytes IoT Lab → Dashboard

 Parameters
- Temperature
- Humidity

 Results
Successfully transmitted live telemetry data to the Zelbytes IoT Lab cloud using HTTPS and MQTT protocols. Data was visualized using both the built-in dashboard and a custom HTML dashboard.
